En un prompt

Donnez ce texte à votre agent (Claude Code ou un autre agent qui travaille dans un terminal), en remplaçant ce qui est entre crochets.

Clone https://github.com/killerwolf/StudioVisualIdentity et lis son AGENTS.md (il est en anglais, c'est normal).
Ma chaîne : [sujet, ex. quiz de géographie], pour [public, ex. ados de 13 à 17 ans], en [langue].
Propose-moi 3 styles adaptés, avec leur vidéo d'exemple, et attends mon choix.
Ensuite, crée notre studio avec out/tools/bootstrap_studio.py, installe ce qu'il faut,
adapte le style à notre chaîne et réalise notre premier épisode sur [sujet de l'épisode].
1. Le style

L'agent lit le dépôt et vous propose 3 styles adaptés à votre sujet et à votre public. Vous choisissez.

2. Le studio

Il crée un projet séparé pour votre chaîne : votre style, des modèles de scènes, les outils de rendu.

3. L'épisode

Il réalise votre premier short, voix off et sons mixés, puis le suivant, et le suivant.

Avant de commencer, il vous faut
  • un agent IA qui travaille dans un terminal, par exemple Claude Code ;
  • git, Python 3.11, Node.js, ffmpeg, et Chromium pour les styles rendus dans un navigateur. Votre agent peut les installer ;
  • une clé Gemini pour la voix off. Le quota gratuit permet environ 10 voix par jour.

La démo, avec le son

41 secondes pour voir les 18 styles, le prompt et les premiers épisodes.

Ce que ça fait, et ce que ça ne fait pas

Ça fait

  • Vous proposer un style visuel, montré sur de vraies vidéos.
  • Créer votre studio : votre style, des modèles de scènes, rendu, voix off, sons, contrôle qualité.
  • Produire vos épisodes avec votre agent, un par un.
  • Fabriquer de nouveaux styles avec le skill fabrique-identites.

Ça ne fait pas

  • Écrire et valider les sujets à votre place.
  • Relire, publier ni programmer vos vidéos.
  • Les vidéos horizontales (16:9) et le format long : pas encore.
  • Publier à votre place : vous gardez la main à chaque épisode.

Vous avez déjà votre propre studio ? Servez-vous du dépôt seulement pour choisir le style, puis transposez-le dans votre moteur.
